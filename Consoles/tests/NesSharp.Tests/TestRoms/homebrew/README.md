# Homebrew games

Real, playable homebrew NES games (not diagnostic ROMs), fetched from the
[retrobrews/nes-games](https://github.com/retrobrews/nes-games) curated collection, used here
to exercise mappers beyond NROM with actual game content instead of just test ROMs.

- `cheril-the-goddess.nes` — *Cheril the Goddess* by na_th_an / Mojon Twins. Mapper 2
  (UxROM), confirmed both by its own ROM-info notes and by inspecting the header directly.
  Licensed CC BY-NC-SA 3.0.
- `novathesquirrel.nes` — *Nova the Squirrel* by NovaSquirrel. Mapper 1 (MMC1), confirmed by
  inspecting the header. Fully open source (GPL-licensed engine); free to distribute or sell
  with source provided.
- `lala.nes` — *Lala the Magical* by Mojon Twins. Mapper 66 (GxROM), confirmed by inspecting
  the header. Licensed GNU LGPL v3.

None of these are commercial titles — unlike the mapper's *typical* commercial games (Zelda,
SMB+Duck Hunt, etc.), these are freely redistributable by their authors' own license terms.
